# Credits, references and attribution

This is an independent maker project.

## Research references

- [GP2040-CE — OpenStickCommunity](https://github.com/OpenStickCommunity/GP2040-CE) — XInput driver/descriptor research and controller protocol comparison; MIT-licensed upstream project.
- [TinyUSB](https://github.com/hathach/tinyusb) — USB device stack and extension points.
- [Arduino-ESP32](https://github.com/espressif/arduino-esp32) — Arduino environment and ESP32-S3 USB integration.
- [Adafruit MCP23017 library](https://github.com/adafruit/Adafruit-MCP23017-Arduino-Library) — MCP23017 I²C IO expander support.

## Attribution review required before distribution

If exact source code or substantial portions from upstream projects were copied or adapted into firmware, preserve copyright/license notices and comply with the relevant licenses. Researching published reports and independently reimplementing behavior is not the same as copying upstream source. The provenance of each final source file should be checked before choosing the repository license.
